# 皿洗いオート (DishAuto)

皿洗いゲーム用の自動操作ツールです。指定した範囲の中で **左クリックを押したまま（オフにも設定可）カーソルを動かし続け**、一定間隔で **スペースキー（洗剤）** を押します。

## 必要環境
- Windows 10 / 11（64bit）
- `publish/DishAuto.exe` は .NET ランタイム込みの単体 exe なので、追加のインストールは不要です。
- ソースからビルドする場合は .NET 8 SDK が必要です。

## 使い方
1. ゲームを **ウィンドウモードかボーダーレス** で起動します。排他フルスクリーンでは範囲選択の画面が表示できません。
2. `DishAuto.exe` を起動します。
3. **形状** を選びます（丸い皿なら「楕円」）。
4. **範囲を選択…** を押し、皿の上をドラッグで囲みます（Esc / 右クリックでキャンセル）。
5. パターン・速度・洗剤の間隔などを設定します。
6. **開始 (F9)** を押し、カウントダウンの間にゲーム画面をクリックして前面にします。
7. 止めるときは **F10** か **Esc** を押します。マウスを手で大きく動かしても止まります。

設定は `%AppData%\DishAuto\settings.json` に保存され、次回起動時に読み込まれます。

## 設定項目
| 項目 | 説明 |
|---|---|
| 形状 | 矩形 / 楕円（選んだ矩形に内接する楕円） |
| パターン | ジグザグ（横・縦）、渦巻き、ランダム、円を描いて擦る |
| 移動速度 | カーソルの移動速度（px/秒）。速すぎると擦った判定にならないことがあります |
| 線の間隔 | 往復する線の間隔。小さいほど細かく擦ります |
| 移動方式 | 通常は「絶対座標」。反応しない場合は「相対移動」を試してください |
| クリック | 「左クリックを押したまま動かす」をオフにすると、カーソルを動かすだけになります（既定はオン） |
| 洗剤 | 指定した秒数ごとにスペースを押します（開始直後に1回押します） |
| 押し直し | 押しっぱなしだと反応しなくなるゲーム向け。指定秒ごとに左ボタンを離して押し直します（「クリック」がオンのときのみ） |
| 制限時間 | 指定秒数で自動停止します（0 = 無制限） |
| 安全 | 手でマウスを動かしたら停止 / 前面ウィンドウが変わったら停止 / 実行中は最小化 |

## うまく動かないとき
- **何も反応しない**: ゲームが管理者権限で動いている可能性があります。DishAuto も「管理者として実行」してください（常に必要なら `app.manifest` の `asInvoker` を `requireAdministrator` に変更）。
- **カーソルは動くが汚れが落ちない**: 移動速度を下げる、移動方式を「相対移動」にする、「押し直し」を設定する、を試してください。
- **相対移動だと位置がずれる**: Windows の「ポインターの精度を高める」をオフにしてください。
- **すぐ「マウスが手で動かされた」で止まる**: ゲームがカーソル位置を補正している可能性があります。「マウスを手で動かしたら停止」をオフにしてください（Esc / F10 では止められます）。
- **F9 / F10 が効かない**: 他のアプリが同じキーを使っています。画面のボタンで操作してください。
- **アンチチート機能があるゲームやオンラインランキングがあるゲームでは使わないでください。**

## ビルド
```powershell
dotnet build -c Release
# 単体 exe の作成
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o publish
```

## 構成
```
DishAuto/
├── MainWindow.xaml(.cs)        メイン画面、開始・停止、ホットキー
├── Views/RegionSelectWindow    全画面オーバーレイで範囲選択（物理ピクセルで取得）
├── ViewModels/                 画面の状態
├── Settings/                   設定と JSON 保存
├── Core/
│   ├── AutomationRunner.cs     実行ループ（移動・洗剤・停止判定）
│   ├── Region.cs               矩形・楕円の範囲計算
│   └── Patterns/               移動パターン
└── Native/
    ├── InputSender.cs          SendInput によるマウス・キー送信
    ├── HotkeyManager.cs        グローバルホットキー (F9 / F10)
    └── NativeMethods.cs        Win32 API 定義
```
